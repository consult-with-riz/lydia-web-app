PHASE 00
Advisor Training Foundation
Pre-client · Klontz core
Training Agent
Psychology Curriculum Agent
Delivers Klontz framework content — money scripts, financial disorders, behavioral biases — as structured learning modules. Tracks advisor mastery.
IN → Advisor profile, learning history
OUT → Competency scores, unlocked capabilities
Training Agent
Role Play Simulation Agent
Simulates difficult client conversations — money avoidance, financial conflict, trauma — so advisors practice behavioral skills before real sessions.
IN → Scenario type, advisor skill level
OUT → Session debrief, skill gap report
Training Agent
Bias Calibration Agent
Surfaces the advisor's own money scripts and cognitive biases. Prevents projection onto clients. Builds self-awareness before client-facing work begins.
IN → Advisor assessments, reflections
OUT → Personal bias profile, watchlist flags

PHASE 01
Prospecting & Discovery
Advisor-facing · Pre-engagement
Intake Agent
Prospect Behavioral Screen
Analyzes early signals — questionnaire responses, stated goals, language patterns — to form an initial psychological profile before the first meeting.
IN → Intake form, prospect data
OUT → Preliminary money script hypothesis
Prep Agent
Discovery Session Prep Agent
Briefs the advisor before the discovery call. Suggests opening questions, flags likely emotional triggers, recommends communication style based on early profile.
IN → Prospect profile, advisor style
OUT → Pre-session brief, question set
Analysis Agent
Discovery Debrief Agent
Processes discovery call transcript or notes. Extracts emotional themes, values signals, and relationship-to-money patterns. Seeds the client's behavioral profile.
IN → Call transcript / advisor notes
OUT → Behavioral profile v1, CRM update
↓
PHASE 02
Onboarding & Deep Profiling
Joint (advisor + client)
Assessment Agent
Money Script Assessment Agent
Delivers validated Klontz Money Script Inventory (KMSI) or equivalent. Scores and interprets results. Maps client to money script archetypes with clinical accuracy.
IN → Client responses to KMSI
OUT → Money script profile, risk flags
Life Planning Agent
Financial Life Guide Agent
Guides the client through values clarification and life goal elicitation. Captures what money means to them — not what they have, but what they want it to do.
IN → Client responses, life domains
OUT → Values map, prioritized life goals
Profile Agent
Behavioral Profile Synthesizer
Integrates money scripts, life values, financial history, and emotional patterns into a unified behavioral profile. This becomes the persistent intelligence layer for all downstream agents.
IN → All Phase 01–02 outputs
OUT → Master behavioral profile (living doc)
Advisor Prep
Advisor Coaching Agent
Translates the client's behavioral profile into advisor guidance. "This client has money avoidance scripts — here's how to frame goal-setting conversations with them."
IN → Behavioral profile
OUT → Tailored advisor playbook per client
↓
PHASE 03
Ongoing Planning & Client Engagement
Client-facing · Recurring
Session Agent
Meeting Prep Agent
Before every review meeting, synthesizes what's changed — market events, life events, profile drift — and prepares the advisor with behavioral context and talking points.
IN → Profile, prior meeting notes, market data
OUT → Meeting brief, agenda, question prompts
Behavioral Agent
Behavioral Intervention Agent
Detects emotional triggers and behavioral risks in real-time — panic selling signals, avoidance patterns, impulse decisions — and provides the advisor with de-escalation scripts.
IN → Client communication, behavioral signals
OUT → Alert + recommended advisor response
Planning Agent
Values-Aligned Plan Agent
Ensures financial planning recommendations are anchored to the client's values profile, not just risk tolerance. Flags when a plan recommendation conflicts with stated life goals.
IN → Plan draft, values map
OUT → Alignment score, conflict flags, rewrites
Client Agent
Client Check-In Agent
Periodic lightweight client touchpoints between advisor meetings. Captures emotional state, life events, and goal progress. Updates the behavioral profile continuously.
IN → Client responses, calendar triggers
OUT → Profile update, advisor summary
Crisis Agent
Life Event Response Agent
Activated by major life events — divorce, death, job loss, inheritance — with specialized behavioral guidance for the advisor and tailored support pathways for the client.
IN → Life event trigger, existing profile
OUT → Event-specific advisor playbook + referral triggers
Post-Meeting
Session Debrief Agent
Processes meeting notes or transcript post-session. Captures decisions, emotional themes, next steps. Updates the profile and generates a client-facing follow-up summary.
IN → Meeting notes / transcript
OUT → Profile update, action items, client email
↓
PHASE 04
Orchestration & Intelligence Layer
Cross-cutting · Always-on
Super Agent
Lydia Super-Agent
The central orchestrator. Routes tasks to the right specialist agent, manages context across the full client history, and ensures behavioral profile consistency across all touchpoints.
IN → Any request from advisor or client
OUT → Routed to correct agent with full context
Memory Agent
Behavioral Profile Store
The living persistent memory of the client relationship. Updated after every interaction. Every agent reads from and writes to this store — it's the shared context layer across all phases.
IN → Outputs from all agents
OUT → Enriched context passed to any agent on request
Quality Agent
Referral Threshold Agent
Monitors for clinical escalation signals — financial trauma, severe anxiety, relationship breakdown — and surfaces referral recommendations to the advisor when Lydia's scope should yield to a therapist.
IN → Session outputs, profile flags
OUT → Referral alert + suggested resources
Analytics Agent
Advisor Performance Agent
Tracks advisor behavioral skill development over time — are they applying psychology concepts, handling difficult conversations well, improving client retention? Feeds back into training.
IN → Advisor session data across all clients
OUT → Skill progression report, training triggers

This is a phase-level agent map — not a technical spec. Each agent represents a discrete behavioral function. The next step is defining inputs, outputs, and handoff logic per agent, then sequencing into buildable sprints.
